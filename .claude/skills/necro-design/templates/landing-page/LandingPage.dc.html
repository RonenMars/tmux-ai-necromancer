tmux-ai-necromancer

Resurrecting dead coding agents. Never lose your agent's train of thought — restore your entire terminal exactly where you left off.

› Restore Session Read the Docs
$ set -g @plugin 'RonenMars/tmux-ai-necromancer'
$ necro-restore.sh
RESTORING claude --resume a1b2c3…
→ codex resume 9f8e7d
→ reanimated 12 panes across 4 sessions
Walks every tmux pane on a timer and records each agent + resumable session id — in the background, off the status bar. Preserves and resumes live Claude Code & Codex loops across crashes and machine restarts. One adapter file per agent. Auto-saves tmux windows, panes, and directory states to a JSONL snapshot. Idempotent restore fills gaps, never duplicates. Pairs with tmux-resurrect + continuum to bring your whole layout — and every agent — back automatically after a reboot.
